# 星际增量帝国游戏 — 项目愿景文档

**项目代号:** first2d  
**引擎:** Godot 4.4  
**类型:** 增量 / 挂机游戏  
**视角:** 2D  

---

## 游戏概述

玩家扮演一个星际帝国的领袖。游戏开始时帝国只有人类一个物种。随着疆域扩张，帝国会遭遇新的外星文明——征服、结盟或重新接纳守护故土千年的古老种族——这些物种逐渐加入帝国并贡献人口。每局开始时根据帝国当前人口比例随机生成主角，然后通过挂机积累研究点数，手动点击科技节点来发展帝国。

---

## 核心玩法循环

```
挂机流逝 → 积累研究点 → 手动点击研究科技 → 帝国获得增益 → 循环
```

## 物种系统

物种列表是**动态的**，随游戏进程扩展，不是固定集合。

### 游戏开局
- 帝国仅有**人类**一种（人口占比 100%）

### 物种加入时机
帝国扩张疆域时，通过以下方式接触新物种：
- **征服/外交**：遭遇新的外星文明，谈判或战争后并入帝国
- **重新接纳**：发现千年前人类/其他种族遗留的故土，古老族裔重归帝国版图

### 物种属性定义（天赋系统）

物种的特征不是简单的数值属性，而是**天赋（Talent）**——每个天赋是一条具体的游戏效果。

#### 全局天赋池
所有天赋存在一个**全局天赋池**中，游戏开始时仅有少量天赋（约5个），随着科技发展和游戏进程，池中天赋数量持续增加。

天赋示例：

| 天赋 ID | 天赋名 | 效果 |
|---------|-------|------|
| `talent_brute` | 大力 | 物理攻击 +10% |
| `talent_keen` | 聪慧 | 法力上限 +10% |
| `talent_psionic` | 灵感 | 科研速度 +5% |
| `talent_tough` | 强韧 | 生命值 +15% |
| … | … | … |

#### 物种天赋分配
- 每个物种在定义时，持有一组**可拥有的天赋 ID 列表**（从全局池中选取）
- 角色生成时，从该物种的天赋列表中随机抽取若干个天赋赋予主角

| 物种（示例） | 可用天赋池（示例） |
|-------------|-----------------|
| 人类 | 大力、聪慧、强韧 |
| 示例外星种族 A | 灵感、聪慧、… |

#### 跨物种天赋继承（社科解锁）
社科科技树中存在特殊科技，例如**「物种通婚政策」**，解锁后：
- 角色生成时，除本物种天赋外，还可**随机继承**其他已加入帝国物种的天赋
- 继承概率、继承数量可由后续科技进一步提升

### 人口比例与角色生成
- 帝国维护一张 `{ 物种ID → 人口百分比 }` 的字典，所有物种比例之和为 100%
- 每次生成主角时，按比例加权随机抽取物种
  - 示例：人类 95%、种族A 5% → 95% 概率生成人类主角
- 主角属性按该物种属性模板随机生成

## 科技系统

### 三种研究点数（货币）

理科、工科、社科是三种**独立积累的点数资源**，挂机时自动产出，玩家用它们解锁科技。

| 点数 | 符号 | 主要来源 |
|------|------|---------|
| 理科点 | S | 基础产出 + 理科相关科技加成 |
| 工科点 | E | 基础产出 + 工科相关科技加成 |
| 社科点 | C | 基础产出 + 社科相关科技加成 |

### 科技解锁规则

每项科技有**两个条件**，同时满足才可研究：

1. **前置科技**：必须已解锁指定的其他科技
2. **点数花费**：消耗指定数量的各类点数（可跨多种）

示例：

| 科技 | 前置 | 花费 |
|------|------|------|
| 基础物理 | 无 | 500 S |
| 反物质研究 | 基础物理 | 10k S |
| 反物质炮 | 反物质研究、轨道工程 | 100k S + 200k E |
| 物种通婚政策 | 多元文化 | 50k C |

### 研究机制
- 玩家**手动点击**科技节点触发研究
- 满足前置 + 点数充足时节点高亮可点
- 点击后立即扣除点数，解锁效果永久生效

---

## 挂机时间系统

- 使用**现实时间**换算为游戏内天数
- 存档时记录 Unix 时间戳
- 读档时计算时间差，补算期间应积累的研究点数
- 每天产出基础研究点数，科技可提升产出倍率

| 科技树 | `TechTree.tscn` | 三分支科技节点 UI |
| 角色卡 | `CharacterSheet.tscn` | 当前主角属性展示 |
